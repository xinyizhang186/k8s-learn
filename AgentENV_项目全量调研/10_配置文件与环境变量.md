# AgentENV：配置文件与环境变量

> 调研日期：2026-08-31  
> 范围：AgentENV 官方 `latest` 文档、GitHub 主仓库与 Releases。  
> 版本提示：tagged release 与 `main/latest` 请分开理解。

> 本文整理当前 `main/config/default.toml` 与 Configuration 文档中的主要配置面。默认值会随版本演进，固定部署应重新核对对应 tag。

## 1. 基础路径

当前默认配置可见：

```text
home_path    = /var/lib/aenv
runtime_path = /run/aenv
deps         = $AENV_HOME/deps
```

理解：

- `/var/lib/aenv`：持久数据；
- `/run/aenv`：临时运行态；
- `$AENV_HOME/deps`：Runtime 依赖。

## 2. 常用环境变量

```bash
AENV_API_KEY=...
API_ADDR=0.0.0.0:8000
AENV_CONFIG_PATH=config/default.toml
SANDBOX_PROXY_DOMAINS=...
AENV_CUSTOM_EXTENSION_URL=...
```

`API_ADDR=0.0.0.0:8000` 可能监听所有网卡，生产必须配合网络 ACL/防火墙/Reverse Proxy。

## 3. Virtualization

默认主路径是：

```text
kvm
```

另有 PVM 模式。Snapshot、Guest Kernel 与 virtualization mode 的兼容性要按版本验证。

## 4. Firecracker

配置维度包括：

- Firecracker binary；
- Guest kernel；
- boot args；
- tools disk；
- control-plane port。

当前 main 默认 boot args 中可见 `mitigations=off`，属于性能/安全 trade-off，应单独审查。

## 5. Image

当前默认解析方向包括：

```text
default image: ubuntu:24.04
search registries:
- docker.io
- ghcr.io
```

支持 allowed registries。生产建议启用 Registry allowlist 和 digest pinning。

## 6. Cache 与 GC

当前 main 可见默认量级：

```text
image cache        ≈ 100 GiB
remote block cache ≈ 100 GiB
```

GC 维度：

```text
enabled
interval
min_age
high_watermark
low_watermark
```

当前可见默认口径约：

```text
interval ≈ 1800 s
min_age  ≈ 600 s
high     ≈ 0.95
low      ≈ 0.70
```

这些只是开源默认参数，不等于生产最佳值。

## 7. Network

当前内部网络默认可见：

```text
host interaction: 10.11.0.0/16
veth:             10.12.0.0/16
tap link:         169.254.0.20/30
```

同时存在 node-level `always_denied_cidrs`。部署前必须检查与企业 VPC/IDC CIDR 的冲突。

## 8. Machine

当前 main 默认机器资源大致：

```text
memory = 1024 MiB
vCPU   = 2
```

还支持 Disk I/O rate limiting：

- bandwidth；
- IOPS。

用于抑制单个 Sandbox 抢占 Host I/O。

## 9. envd

当前 main 配置中可见 envd version 约为 `0.5.15`，并设置 init timeout 与毫秒级 poll interval。

固定 release 时必须以对应配置为准。

## 10. Snapshot Backend

主要配置面：

```text
repository_backend
backend.posix_fs
backend.oss
image_publish
p2p_enabled
memory snapshot
background download
```

### POSIX

适合共享文件系统。

### OSS

适合 S3-compatible/object storage。

## 11. Memory Snapshot

当前 main 可见：

```text
track_dirty_pages = true
compression       = false
algorithm         = lz4
workers           = 1
```

“配置了算法”不代表 compression 默认已经启用。

PVM 模式下 dirty-page tracking 行为可能不同。

## 12. Background Download

配置维度：

```text
enabled
block_size
concurrency
max_inflight
```

用于恢复过程中边运行边获取远端内存 Artifact。

## 13. P2P

当前明确为 Experimental，默认：

```text
enabled = false
transport = iroh
```

还包含 store、timeout、provider 等配置。

## 14. Pool / Prewarm

AgentENV 会预热一部分资源，配置包括：

- network maintenance pool；
- block pool；
- Firecracker pool；
- startup prewarm；
- low/high watermark。

当前 main 可见默认量级：

```text
low  = 2
high = 64
```

## 15. OverlayBD / ublk

可配置：

- runtime upper 模式；
- shrink；
- download；
- metrics。

当前 ublk metrics 配置中可见类似：

```text
0.0.0.0:9103
```

生产环境不要无保护暴露。

## 16. Observability / Scheduler Reporting

配置包括：

- observability enabled；
- metrics/logging；
- scheduler resource report；
- report interval。

分布式资源调度前，应确认 Node metrics reporting 是否实际启用。

## 17. 推荐配置管理方式

```text
upstream default.toml
→ environment-specific override
→ secrets injection
→ immutable deployment
```

不要直接手改默认文件而不记录差异。

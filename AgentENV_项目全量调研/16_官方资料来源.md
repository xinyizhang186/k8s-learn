## 1. 本资料包的来源原则

核心事实只以这些来源为准：

1. AgentENV 官方 `latest` 文档；
2. `kvcache-ai/AgentENV` GitHub 主仓库；
3. GitHub Releases；
4. 仓库内 README、Cargo.toml、go.mod、default.toml 和 Developer Internals。

没有把第三方博客转述当作核心项目事实。

## 5. 版本边界

截至 2026-08-31：

```text
latest tagged GitHub Release: v0.1.2
main Rust workspace version:  0.1.3
```

因此所有涉及 `main/config/default.toml`、main 源码目录和 `latest` 文档的结论，都应理解为“当前公开开发状态”，不能自动推导为 v0.1.2 已完全包含。

## 6. 推荐固定版本的方法

实际研究/部署时记录：

```text
release tag
git commit SHA
Cargo workspace version
Go module version/toolchain
config/default.toml hash
Firecracker version
envd version
Guest Kernel
Host Kernel
virtualization mode
```

这样性能和故障结果才可复现。

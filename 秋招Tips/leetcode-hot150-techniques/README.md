## 八股背诵策略

1. **第一遍(通读)**:按上面顺序读,理解每个模板为什么这么写
2. **第二遍(背要点)**:只看每节标题 + 速记口诀,用关键词展开
3. **第三遍(默写)**:对着"自测清单",能否 30 秒默写每个模板的核心骨架
4. **面试前一晚**:只看每篇的"速记口诀 + 对比表"和"避坑清单"

> 口诀总览:
> - **DP**:"最后一步想清楚,状态转移自然有;背包逆序完全序,滚动数组别覆盖。"
> - **字符串**:"子串想滑窗,匹配想 KMP,回文 Manacher,Trie 找前缀。"
> - **图**:"连通 DFS/BFS,最短 Dijkstra,拓扑判环并查集,带权用加权并查。"
> - **二叉树**:"分治靠后序,遍历靠栈,路径和用前缀,BST 用中序。"

## 薄弱点专项突破建议

- **DP 薄弱** → 背"最后一步"思想 + 背包两版 + 股票状态机。先默写,再刷题。
- **字符串薄弱** → KMP 和 Manacher 是分水岭。**务必打开 `02-strings.md` 手敲一遍 KMP 的 `lps` 数组和 Manacher 的 `#` 插值**,不敲永远记不住。
- **图论薄弱** → 核心是"认出是图"和"状态维度设计"。每做一道图题问自己:**"节点会被重复经过吗?后续行为不同吗?"** 不同 → 把额外维度塞进 BFS 状态。
- **二叉树薄弱** → 核心是"返回值 vs 全局 ans"。每做一道树题问自己:**"返回值服务谁?答案从哪里取?"**

## 通用答题框架(适用于"设计一个 X 系统"类场景题)

1. **需求澄清**:输入是什么?输出是什么?QPS?延迟要求?数据量?准确率要求?
2. **整体架构**:画模块图(输入处理 → 核心 → 输出)
3. **关键模块**:每个模块的技术选型 + 理由
4. **数据流**:数据怎么流转,缓存/队列在哪
5. **优化点**:性能、成本、准确率分别怎么优化
6. **容错降级**:失败怎么办,降级到什么
7. **监控评估**:埋什么点,怎么持续优化
8. **权衡取舍**:为什么这么选,代价是什么

> 面试官追问时,先说"我的方案有几个权衡点",再展开——比直接给答案更显成熟。
